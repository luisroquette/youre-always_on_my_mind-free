# Replit

Use the generic JSONL importer or run this local MCP server from a machine that
can access its memory bridge. Replit's hosted MCP server is a separate remote
service; do not place local database paths, bridge paths, or passphrases in a
Replit secret or public project.

For local Agent SDK projects, use the same stdio command as the generic example:

```text
node /absolute/path/to/youre-always_on_my_mind/src/index.js
```
